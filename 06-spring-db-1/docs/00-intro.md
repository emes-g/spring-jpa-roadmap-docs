## 스프링 DB 1편 - 데이터 접근 핵심 원리
### 웹 애플리케이션의 기본 구조
- **현대 애플리케이션은 대부분 웹 환경에서 동작하는 웹 애플리케이션**이다.
- 웹 애플리케이션은 **기능에 따라 크게 3가지 계층으로** 나뉜다.
  - **컨트롤러:** 웹이나 앱 클라이언트의 요청을 받아 처리한다.
  - **서비스:** 애플리케이션의 핵심 비즈니스 로직을 처리한다.
  - **레포지토리:** 서비스 로직의 수행 결과를 DB에 반영하고 관리한다.

#### 백엔드 개발의 핵심 축
> **백엔드 개발은 HTTP 기반의 스프링 MVC와 DB 기반의 스프링 데이터 접근 기술이라는 두 가지 핵심 축으로 구성**된다.

### 데이터 접근 기술 학습의 어려움
> **애플리케이션에서 DB 데이터를 관리하기 위해서는 데이터 접근 기술을 학습해야 하지만, 학습 과정에서 다음의 어려움이 존재**한다. 

#### 1. DB 기반 지식 부족
- 모든 데이터 접근 기술은 DB에 데이터를 보관하고 관리하기 위한 것이라서, **DB에 대한 기본 이해가 선행**되어야 한다.

#### 2. 데이터 접근 기술의 다양성
- JDBC를 시작으로 SQL Wrapper인 JdbcTemplate, MyBatis, 그리고 ORM 기술인 스프링 데이터 JPA, QueryDSL 등 다양한 데이터 접근 기술이 존재한다.
- **기술이 너무 다양하기 때문에, 오히려 각각의 장단점과 적절한 사용 상황을 판단하기 어렵다.** 

#### 3. 오랜 역사와 고도의 추상화
- 20년 이상 발전해 온 **데이터 접근 기술들은 스프링 프레임워크에 의해 고도로 자동화 및 추상화**되었다.
- 단순히 사용하는 것 자체는 어렵지 않지만, **기술의 등장 배경이나 맥락을 이해하지 못한 채 사용하게 되는 현상이 바람직하다고 할 순 없다.**

### 스프링 DB 강의 로드맵
> 상기 언급한 문제들을 해결하기 위해, 본 강좌에서는 **과거의 문제점과 기술의 발전 과정을 하나씩 직접 경험해 보며 단계적으로 학습**한다.

#### 스프링 DB 1편 - 데이터 접근 핵심 원리
![스프링 DB 1편](./images/spring-db-1.png)

- **데이터 접근 기술의 기초와 핵심 원리를 다지는 과정**이다.
- **주요 학습 내용:**
  - 데이터 접근 기술의 시작인 JDBC
  - DB 연결 관리를 위한 커넥션 풀과 데이터소스(DataSource)
  - 데이터 정합성을 보장하는 DB 트랜잭션
  - DB와 연동되어 동작하는 기초 자바 예외 매커니즘
  - 스프링 데이터 접근 기술 (트랜잭션 원리, 예외 처리, JDBC 반복 해결)

#### 스프링 DB 2편 - 데이터 접근 활용 기술
![스프링 DB 2편](./images/spring-db-2.png)

- 기초를 다진 후, **다양한 데이터 접근 기술을 학습하는 과정**이다.

  - 데이터 접근 계층에 대한 테스트 방법
  - 스프링 트랜잭션 기능
  - 실무 활용 방안
